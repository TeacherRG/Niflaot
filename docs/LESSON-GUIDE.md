# Как сделать новый урок

Пошаговый порядок, по которому сделаны уроки №1 «Тикун парцуф-занав» и №2 «Йикаву ґа-маим».
Следующие уроки делаются **так же**: это обязательный стандарт проекта.

---

## 1. Материал

1. Исходник — брошюра «Нифлаот» (PDF), текст статьи рава Ицхака Гинзбурга или классический комментарий
   (например, Бааль ґа-Турим: текст и издание — из Sefaria, автор указывается в поле `author` урока).
2. Текст из PDF: `pdftotext -f <стр> -l <стр> файл.pdf -` (**без** `-layout` — иначе иврит идёт в обратном порядке).
3. Прочитать статью **целиком** до начала работы. Урок = одна статья (шиур / рашима).

## 2. Файлы урока

```
src/lessons/NN-slug/
  index.ts        данные без языка: ивритские слова, ответы, варианты, уравнения, источники
  i18n/ru.ts      все тексты по-русски
  i18n/en.ts      все тексты по-английски
  i18n/de.ts      все тексты по-немецки
```

Английский и немецкий тексты — по `docs/TRANSLATION-GUIDE.md` (транслитерация и слова chabad.org / de.chabad.org,
простой немецкий для детей).


- Скопировать папку предыдущего урока и заполнить заново.
- Зарегистрировать урок в `src/lessons/index.ts`.
- Указать главу: `parsha: 'bereshit'` (новую главу добавить в `src/lessons/parshiot.ts` с годом).

## 3. Загадки

- 4 загадки по 3–5 шагов. Шаг — число (`num`), выбор из 4 вариантов (`ch`) или буквенная головоломка
  (`lt`, `tap` — см. ниже). Не всё должно быть счётом: там, где источник играет буквами (ראשי/סופי תיבות,
  перестановка букв, полное и неполное написание), лучше буквенный шаг, чем выбор из вариантов.
- Числовые шаги — с подсказкой (`hint`) и **обязательно с разбором `coach`** в `index.ts`. Это данные для модуля
  `src/core/coach.ts`: ему передают **ивритские слова или числа**, а не готовые строки — буквы и их значения
  модуль берёт сам, поэтому опечатка в числах невозможна:
  ```ts
  { t: 'num', a: 420, coach: [{ word: 'היתה' }] }                                   // ה 5 + י 10 + ת 400 + ה 5
  { t: 'num', a: 471, coach: [{ word: 'זנב' }, { word: 'תאוה' }, { add: ['$1', '$2'] }] }
  { t: 'num', a: 256, coach: [{ word: 'מקוה' }, { word: 'קו' }, { word: 'תקוה' },
                              { add: ['$1', '$2', '$3'] }, { div: ['$4', 3] }] }   // '$k' — результат k-го действия
  { t: 'num', a: 59,  coach: [{ div: [3068, 52] }] }
  ```
  Действия: `word`, `add` (много слагаемых), `sub`, `mul`, `div` (нацело). Задача на счёт без вычислений
  (например, «сколько слов») помечается `count: true`.
- **Не только обычная гиматрия.** Малая гиматрия, порядковое и большое число, полное написание (מילוי),
  колель, атбаш, альбам, нотарикон и другие приёмы — по **`docs/GEMATRIA-RULES.md`**: `{ word, method: 'atbash' }`
  в `coach`, `method: 'milui'` у шага выбора, `notarikon: 'בראשית'` у шага-нотарикона. Способ называется
  и объясняется в условии; если комментатор пишет «гиматрия», а сходится только другим способом, — это сказано
  в тексте урока. Примеры: урок «Бааль ґа-Турим: Ноах», загадка 5 (колель, атбаш); урок №1, загадка 1, шаг 5 (нотарикон).
- **Буквенные шаги** (модуль `src/core/letterPuzzle.ts`, компонент `src/components/LetterSteps.tsx`):
  ```ts
  { t: 'lt', est, from: 'בראשית ברא אלהים', take: 'last', a: 'אמת' }   // «Собери слово»: סופי תיבות
  { t: 'lt', est, from: 'האדם לנפש חיה', take: 'first', a: 'חלה' }     // ראשי תיבות (порядок можно менять)
  { t: 'lt', est, from: 'בהבראם', take: 'all', a: 'באברהם' }           // перестановка всех букв
  { t: 'tap', est, word: 'מאורת', a: 2, written: 'מארת' }             // «Найди букву»: какой нет в Торе
  ```
  Игрок нажимает буквы стиха (или слова) в том порядке, в каком они стоят в ответе. В `lt` засчитывается
  только слово из «правильных» букв: то же слово из других мест стиха — отдельная подсказка «буквы не
  оттуда», верные буквы в неверном порядке — подсказка «переставьте». Подсказка подсвечивает нужные буквы.
  После 3 неверных попыток код сам раскладывает ответ в ячейки и подсвечивает его буквы в стихе.
  **Правило текста для `lt`:** условие не говорит, в каком порядке нажимать («по порядку», «с конца»,
  «от третьего слова к первому» — нельзя: у Бааль ґа-Турим буквы часто переставлены, אמת из ת·א·ם).
  В условии — какие буквы брать (первые / последние / все) и «буквы можно переставлять»;
  в подсказке (`hint`) — что значит искомое слово («слово из трёх букв, которое значит „истина“»),
  а не порядок букв и не само слово. `npm run check` проверяет, что взятые буквы — ровно буквы ответа, а слово без буквы `a`
  написано как `written`. Конечные формы (ם, ך…) равны обычным. Ответ `lt` не ставить на карточку слова.
- **Возраст урока** (`age`) — нижняя граница, шире — лучше. Ориентиры: сложение трёхзначных чисел, буквенные
  игры, сюжетные темы — 8+; деление многозначных чисел, среднее, умножение — 10+ (4–5 класс); темы
  страсти, брака, глубокая каббала или вычисления уровня 6–7 класса — 12+. Решает самый трудный шаг или тема.
- **Время и сложность шага** (`est`) — обязательно у каждого шага, показываются над шагом и в печати:
  `est: { sec: 60, level: 2 }` — среднее время в секундах и сложность 1 · лёгкий, 2 · средний, 3 · трудный.
  Ориентиры: выбор без счёта или сложение уже известных чисел — 15–30 с, уровень 1; гиматрия одного
  слова из 3–4 букв — 20–45 с, уровень 1; сумма двух-трёх слов или подсчёт букв стиха — 60–90 с,
  уровень 2; деление трёх-четырёхзначных чисел в уме, среднее нескольких слов, полное написание
  букв (מילוי) — 90–150 с, уровень 3. Время загадки («решение» и «чтение урока») сайт считает сам:
  сумма шагов плюс чтение условия, чтение разделов — 130 слов в минуту.
- Тот же модуль работает в калькуляторе гиматрии и в тренажёре «Устного счёта» («Посчитать вместе»).
- **Каждое число проверяется кодом** (см. ниже). Число, которое не сходится, в урок не попадает,
  даже если оно есть в статье. Значения неверных вариантов (`v`) тоже проверяются.
- **Карточки слов** (`words`) — только слова, которые нужно сосчитать для ответа. Карточка не должна
  подсказывать ответ (слово-ответ на карточку не ставить). Можно оставить `words: []`.
- **Каждое ивритское слово, которое видит игрок, должно быть объяснено**: что оно значит и при чём
  оно здесь (имя — чьё и что значит; выражение — откуда цитата). Без «голых» слов.
- В уравнениях и вопросах иврит пишется как есть; в условиях стих целиком — отдельной строкой:
  `<p class="verse" dir="rtl" lang="he">…</p>`, отдельные слова — `<em>…</em>` или `<span class="he">…</span>`.

Проверка гиматрии:

```bash
node --experimental-strip-types -e "import('./src/core/gematria.ts').then(m=>console.log(m.gematria('פרצוף')))"
```

## 4. Тексты (ru, en и de)

Обязательные поля `LessonText` (TypeScript не даст забыть):

| Поле | Что это |
|---|---|
| `riddles[].cond`, `steps`, `reveal` | условие, вопросы, подсказки, разгадка |
| `riddles[].lessons` | **полный пересказ** статьи по разделам — максимально полно, без пропусков мыслей и чисел |
| `riddles[].reflection` | вопрос к себе: «что это меняет во мне прямо сейчас?» |
| `riddles[].takeaways` | 3–5 тезисов для конспекта на экране итога |
| `riddles[].puzzle`, `puzzle` | «Собери смысл»: пазл из ключевых терминов загадки и итоговый пазл всего урока (см. ниже). **Только в связной статье рава Гинзбурга**; у урока-комментария (`kind: 'commentary'` — Бааль ґа-Турим и т. п., отдельные не связанные замечания) пазлов нет |
| `practice` | «Ґораа ле-поаль» — один конкретный практический вывод |
| `age` в `index.ts` + `audience` | возраст «N+» — **минимальный**, с которого урок по силам (диапазон открыт вверх: и взрослым); `audience` — одна фраза, почему (счёт, темы; младшим — со взрослым) |
| `highlight` + `highlight` в `index.ts` | главное равенство и подпись для картинки «Поделиться» |
| `share` | текст «поделиться» — упомянуть **все** загадки урока |
| `glossary`, `summary`, `hero`, `final`, `source` | подписи слов, карточка урока, шапка, итог, строка об источнике |

«Собери смысл» (`PuzzleText`): `q` — принцип порядка, `pieces` — 3–6 ключевых терминов в правильном порядке,
`meaning` — смысл собранной цепочки.
- Порядок должен **однозначно следовать из урока**, а `q` называет его принцип: «по порядку текста»,
  «от правила — к числу — к смыслу», «от внешнего к внутреннему», «от малого к большему». Если два звена
  можно поменять местами без потери смысла — переформулировать или убрать одно.
- Звено — короткий термин или равенство (до ~35 знаков), только то, что есть в уроке. Иврит в звене объяснён рядом.
- Пазл загадки подводит итог её раздела «Урок открыт»; итоговый пазл урока — путь через все загадки.
- Число звеньев одинаково во всех языках (проверяет `npm run check`).

Правила:
- **Ничего не добавлять от себя в уста рава.** Свои формулировки (вопросы к себе, практический
  вывод, тезисы) — только как пересказ или явно как вывод проекта.
- Перед сдачей — сверить пересказ с исходником абзац за абзацем.
- Новые термины (каббала, хасидут) — добавить в словарь `src/i18n/glossary.ts` (ru, en и de).
- Транслитерация иврита по-русски: буква ה в начале и в середине слова — «ґ» (ґа-Турим, Авраґам, Аґарон, Йеґуда,
  Теґилим, Зоґар, Ґораа, Ґавдала, артикль «ґа-»: Рош ґа-Шана); ה на конце слова не пишется (Тора, Шхина, Моше, Сара).
  ח — по-прежнему «х» (Хава, Ноах, Хохма). Названия источников из Sefaria — так же (`scripts/fetch-sources.py`).
- Слова урока для калькулятора — в `calculator.words` (настоящее написание), ответы-«спойлеры» —
  в `calculator.secrets`.

## 5. Имена Всевышнего

- На экране и в печати: `אלקים` вместо полного написания, `ה׳` вместо Имени Ґавая; по-русски
  «Б-г», «Г-сподь», «Б-жий». Гиматрия считается по **настоящему** написанию
  (в `calculator.words` и в расчётах — полное написание, функция `displayNames` заменяет его при показе).
- Исключение — не святые употребления (например, «אלהי זהב», золотой телец).

## 6. Первоисточники (Sefaria) — обязательно

Каждый источник, который цитирует или на который ссылается статья (Тора, Пророки, Писания,
Гемара, Мидраш, Зоґар, Тания, хасидские книги), добавляется в урок в виде
выпадающего блока «Первоисточники»: **оригинал + перевод + ссылка на Sefaria**.

Скрипт: `scripts/fetch-sources.py` (берёт тексты из открытой выгрузки Sefaria —
`storage.googleapis.com/sefaria-export`, API sefaria.org не нужен).

1. Найти книгу и издание:
   ```bash
   python3 scripts/fetch-sources.py ls "Talmud/Bavli/Seder Moed/"
   python3 scripts/fetch-sources.py ls "Tanakh/Writings/Psalms/English/"
   ```
2. Найти место по словам (огласовки не мешают):
   ```bash
   python3 scripts/fetch-sources.py find "Talmud/Bavli/Seder Zeraim/Berakhot" פרצוף זנב
   ```
   Скрипт печатает адрес и готовую строку для `SOURCES`.
3. Добавить строку в `SOURCES` в скрипте (Танах и Бавли — короткой записью,
   остальное — `'custom'` с путями к файлам изданий) и запустить:
   ```bash
   python3 scripts/fetch-sources.py
   ```
   Результат — `src/sources/sefaria.json` (коммитится в репозиторий).
4. Указать источники у загадок: `sources: ['berakhot-61a', 'gen-2-21']` в `index.ts`.
   И **обязательно** поставить сноску в тексте урока (`i18n/ru.ts`, `en.ts` и `de.ts`) сразу после цитаты
   или упоминания: `<sup data-src="berakhot-61a"></sup>`. Сноски нумеруются автоматически по порядку
   чтения (условие → разгадка → разделы урока), цифра ведёт к отрывку, «↩» — обратно в текст.
   Отрывок без сноски в тексте не добавлять.
5. Русский перевод:
   - Тора — берётся из Sefaria автоматически (Д. Сливняк, проект «Да»);
   - всё остальное — перевести с оригинала, сверяясь с английским Sefaria, и добавить
     в `src/sources/ru.ts` (по строке на сегмент, в том же порядке). Такой перевод подписан
     «перевод: проект Нифлаот».
6. Немецкий перевод — тоже из Sefaria, автоматически: Тора — С. Р. Гирш (1867–1878), Пророки и Писания —
   С. Бернфельд (1902), Йехезкель — Й. Бройер (1921), Талмуд — Л. Гольдшмидт (1929), Берешит Раба —
   А. Вюнше (1881). Если немецкой версии нет (Мишлей, Зоґар, Тания, «Мей ґа-Шилоах»…), перевести
   с оригинала и добавить в `src/sources/de.ts`. Для `'custom'` немецкое издание указывается в строке `SOURCES`.
   `npm run check` не пропустит источник без немецкого перевода.

Издания по умолчанию: Танах — *Tanach with Text Only* + *JPS 1917* (общественное достояние);
Бавли — *William Davidson Edition* (CC-BY-NC). Издание и лицензия показываются у каждого отрывка.

## 7. Проверка перед PR

1. `npm run check` — автоматическая проверка урока: итог каждого разбора = ответ, значения вариантов =
   настоящая гиматрия, у каждого источника есть сноска и перевод.
2. `npm run build` — без ошибок.
3. Пройти урок целиком в браузере на ru, en и de (Chromium в `/opt/pw-browsers`, Playwright):
   все ответы засчитываются, разгадки, уроки, первоисточники, конспект, вывод, картинка «Поделиться».
4. Ширина 390 и 360 px — без горизонтальной прокрутки, панель в одну строку.
5. Печать (`#/<slug>/print`) — PDF собирается, иврит не «переворачивается».
6. Все числа проверены кодом; пересказ сверен с исходником.
7. Картинка превью ссылки: `npm i --no-save playwright && npx tsx scripts/og-images.ts` → проверить
   `public/og/<slug>.png` (заголовок, равенство, иврит не «перевёрнут») и закоммитить.

## Memo-игра (уроки-комментарии)

У урока-комментария (`kind: 'commentary'`) **две игры**, равноправные и доступные параллельно:
«Игра с гиматриями» (`#/<slug>`) и «Memo-игра» (`#/<slug>/memo`) — подпункты урока в меню
и кнопки на карточке урока на главной (переключателя под шапкой урока нет). Memo: 24 карты, 12 пар (картинка + слова Торы).

Как строится (методика):
1. **Изучите пары** — все 12 комментариев с картинкой, словами Торы, объяснением и выводом.
2. **Лёгкая игра** — 6 случайных пар (12 карт), потом **полная** — 12 пар (24 карты).
3. После каждой найденной пары — объяснение; в конце — «Что мы узнали» (заголовок и вывод каждой пары).

Данные:
- `src/lessons/NN-slug/memo.ts` (`MemoData`) — без языка: слова Торы (`verse`, карта пары), слова комментария
  (`quote`), `gematria` / `letters` — **только те, что есть в самом комментарии** (`kind`: `rt` ראשי תיבות, `st`
  סופי תיבות, `notarikon`, `letters` — те же буквы), источник Sefaria.
- `memo` в `i18n/ru.ts`, `en.ts`, `de.ts` (`MemoText`): `intro` и для каждой пары — `title`, **`caption`** — пояснение
  к картинке в списке «Что на картинках» под игрой (что изображено и что это значит, до 45 знаков: по нему ребёнок
  ищет пару; на самих карточках подписей нет), `verse` — перевод слов
  Торы, `quote` — перевод слов комментария, `explain` — «Знаете ли вы?» простыми словами, `note` — что значит число,
  если у гиматрии нет равных слов, `moral` — «Чему это учит?» (вывод проекта, не комментатора).
- Интерфейс — на языке сайта; иврит — только слова Торы и цитаты, всегда с переводом.
- Расчёты (`913 + 203 = 1116`, `ת · א · ם`) код строит сам из слов; `npm run check` сверяет числа, буквы и тексты.
- Картинки — 12 раскрасок из генератора изображений (контуры без заливки, без текста, вертикальные 3:4) →
  `python3 scripts/memo-frame.py <папка> src/lessons/NN-slug/memo <Parsha>`: один размер 1200×1600 и подписи —
  название главы латиницей, номер, «© mychitas.app 5787».
- Печать — отдельный вариант `#/<slug>/print/memo`: карточки для вырезания (слова — с переводом) и список «Что на картинках»,
  объяснения пар, раскраски.

## «Нифлаот Ребе» (беседы Любавичского Ребе)

В каждой главе Торы есть пункт меню и раздел на главной «Нифлаот Ребе» (`#/rebbe/<parsha>`) — «Чудеса Торы в учении Ребе».
**Без гиматрий:** подход Ребе другой — вопрос к стиху (часто к Раши), ответ Ребе, вывод для жизни.

Урок раздела: `series: 'rebbe'`, `kind: 'sicha'`, нумерация — своя внутри раздела главы (урок 1, 2…). Пример — `04-shalosh-shaot`.
- **Расследование** (`#/<slug>`) — загадки как обычно, но шаги — выбор (`ch`) и простой счёт без гиматрий
  (`num` с `coach` из чисел). Карточек слов (`words`) нет, калькулятора гиматрии нет; `equations` — ключевые фразы на иврите.
  Порядок: крючок-вопрос → улики (первоисточники) → ответ Ребе → «Урок открыт» (полный пересказ беседы по разделам,
  ничего не добавлять от имени Ребе) → пазлы «Собери смысл» (беседа связная) → «Ґораа ле-поаль».
- **Карточки** (`#/<slug>/cards`) — вторая игра, как Memo, но пары текстовые: стих главы ↔ одно объяснение Ребе
  (из таблицы бесед недели «Ликутей сихот»). **К каждому стиху — только одно объяснение**: если на стих несколько бесед,
  берётся одна. Данные — `cards.ts` (`verse` — слова Торы как в стихе, `source` — стих в Sefaria, `ls` — том и беседа),
  тексты — `cards` в `i18n/<язык>.ts` (`title`, `verse`, `card` ≤ 70 знаков, `explain`, `horaah`,
  `poem` — 4–6 рифмованных строк для «Запомнить в стихах»: стих, объяснение Ребе и вывод, ничего от себя).
  «Прочитать» (`#/<slug>/read`, переключатель «Прочитать / Запомнить в стихах») появляется в меню сам.
  `npm run check` проверяет: 12 пар, слова есть в стихе, стихи не повторяются, длину карточки, тексты на всех языках.
  Печать — `#/<slug>/print/cards`: карточки со стихами и с объяснениями для вырезания, объяснения пар.
