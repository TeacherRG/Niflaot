# Тексты о недельных главах («Глава рождения»)

Третий свиток раздела «Мой удел в Торе» — недельная глава той недели, когда человек родился. Какую главу
показать, игра считает сама: расписание — `data/parsha.json`, проверено по Hebcal на каждом дне 1900–2100 годов,
в Израиле и за его пределами. Правило: глава субботы в день рождения или ближайшей после него; если на эту субботу
выпал праздник и недельной главы не было — предыдущая глава.

Сейчас глава показывается с названием (иврит и язык игры), датой субботы и границами главы. **Тексты о главах
добавляет автор** — пока поля пустые, и пустое просто не показывается.

## Где писать

`content/ru/parsha.json`, `content/uk/parsha.json`, `content/de/parsha.json`, `content/en/parsha.json` — одинаковые
по структуре: список `parshiot` из 54 глав по порядку (Берешит … Ве-зот а-браха). У каждой:

```json
{"he": "בראשית",
 "theme":    {"__ag": 1, "y": "", "t": "", "a": ""},
 "question": {"__ag": 1, "y": "", "t": "", "a": ""}}
```

- `he` — название на иврите, не менять (по нему проверка сверяет порядок).
- `theme` — главная мысль главы, 1–3 предложения: `y` — для 8–11 лет (30–40 слов, просто), `t` — для 12–15,
  `a` — для взрослых 16+ (можно с источником). Если `a` пустое, взрослые видят `t`.
- `question` — вопрос для разговора (например, за субботним столом), тоже по возрастам.
- Формы рода — как везде в игре: `ты {родился|родилась}`. Имена Всевышнего — «Всевышний» / «Всевишній» /
  «G-tt» / «the Almighty». Толкования рава Ашкенази подписывать как его толкования.
- Когда главы читаются вместе (например, Ваякгель – Пкудей), показываются тексты обеих.

## Как проверить

- `npm run test:data` — все четыре языка совпадают по структуре, нет пропущенных форм рода и т. п.
- `npm run test:parsha` — расписание глав совпадает с Hebcal.
- `npm start` → «Мой удел в Торе» → укажи дату рождения → третий свиток.

Тексты о главах показываются, но не озвучиваются (как стих и «Айом-йом»). Перед публикацией — на утверждение раву.

## Если нужно пересобрать расписание

`npm run parsha` (`tools/build-parsha.mjs`) — берёт расписание из Hebcal (только для разработки, в браузер не
попадает) и сам проверяет, что все годы 5500–6400 укладываются в 14 типов года.
