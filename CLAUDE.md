# Niflaot — память проекта

«Нифлаот» — чудеса Торы глазами разных учителей (Тора-проект MyChitas). У каждого автора свой жанр урока:
рав Ицхак Гинзбург (статьи брошюры «Нифлаот») — игры-гиматрии; Бааль ґа-Турим (комментарий) — гиматрии и буквы + Memo;
Любавичский Ребе (беседы «Ликутей сихот», раздел «Нифлаот Ребе») — расследование без гиматрий + карточки.
Общее: игрок сам находит ответ, потом — пересказ, первоисточники Sefaria, вывод для жизни, печать; ru/en/de.
Уроки сгруппированы по недельным главам.
**Три главных раздела — Тора, Пророки, Писания** (см. «Пророки и Писания» ниже): Тора — всё прежнее (уроки глав). Сайт: https://niflaot.mychitas.app
(GitHub Pages, публикация через `.github/workflows/deploy.yml` при пуше в `main`).
Общаться с владельцем проекта — по-русски.

## Стек и команды

- React 19 + TypeScript + Vite, hash-роутинг (`#/`, `#/<slug>`, `#/<slug>/print`, `#/math/<op>`);
  статические `/<slug>/` (SEO) открывают тот же урок.
- `npm install`, `npm run dev`, `npm run build` (tsc + vite + prerender), `npm run check` (проверка данных уроков).
- Браузерные проверки: Playwright + Chromium из `/opt/pw-browsers` (не скачивать браузер).

## «Пророки» и «Писания» — трёхлетний цикл

- Только в меню: «Тора» (главы с уроками) и «Пророки», «Писания» → «Отрывок дня». **Главный экран — как был**, без них.
- Страница `#/neviim[/<дата>]`, `#/ketuvim[/<дата>]` (`TanakhPage.tsx`): по стиху — иврит (масоретский, с огласовками),
  английский перевод, рав Штейнзальц (стих с вплетённым объяснением, he/en; слова стиха — жирным, сноски — мелко),
  его вступления к разделам. **Одна кнопка языков** над текстом (`ViewMenu`, как переключатель языка сайта): показывает
  выбор и открывает список «Язык» — Иврит и русский / Иврит и English / Русский / English / Только иврит (для стиха,
  объяснения и вступлений сразу), под чертой — «Объяснения рава Штейнзальца» (вкл./выкл.); выбор —
  в localStorage `niflaot:tanakh-view`; по умолчанию — иврит и язык сайта (русский сайт — русский, иначе English).
- **Русский перевод проекта** — `src/tanakh/ru/<книга>.json` (`"глава:стих": {t, st, intro: [{title, text}]}`):
  **переводится только то, что есть на английском** — стих из английского перевода (JPS 1985), объяснение и вступления
  Штейнзальца из английского издания; ничего из ивритской версии не добавляется, жирного нет; сноски — `<small class="fn">`

  день показывается по-русски, если переведён целиком (оба раздела), иначе — английский, плашка «перевод готовится»
  и пометка «перевод скоро» в меню. Переведено: **11–25.10.2026**
  (Йеґошуа 1:1 – 7:10, Теґилим 1 – 10:8) — переводить заранее, по неделе.

## Новый урок — всегда по `docs/LESSON-GUIDE.md`

Обязательно для каждого урока:
1. Полный пересказ статьи по разделам (ru + en + de), без добавлений от имени рава.
2. Каждое число и каждый вариант ответа проверены кодом; не сходится — не включать.
   Способы счёта и буквенные приёмы (малая гиматрия, колель, מילוי, атбаш, альбам, ר״ת/ס״ת, нотарикон…) —
   по `docs/GEMATRIA-RULES.md` (код — `src/core/gematriaMethods.ts`; калькулятор показывает слово всеми способами).
   У каждого числового шага — разбор `coach` для модуля `src/core/coach.ts` (слова и числа,
   не строки), его итог = ответ шага. Проверка всего этого — `npm run check` (он же запрещает в HTML-текстах `<script>`, `on…=` и `javascript:`).
   Карточки слов не подсказывают ответ; каждое ивритское слово на экране объяснено (что значит, при чём здесь).
3. Поля: вопрос к себе, тезисы конспекта (`takeaways`), «Ґораа ле-поаль» (`practice`),
   равенство для картинки (`highlight`), текст «поделиться» со всеми загадками,
   пазл «Собери смысл» (`puzzle`) у каждой загадки и итоговый у урока — только в последовательных статьях
   рава Гинзбурга; у уроков-комментариев (`kind: 'commentary'`, Бааль ґа-Турим и т. п.) пазлов нет.
4. **Первоисточники из Sefaria** для всех цитируемых текстов: `scripts/fetch-sources.py ls/find` →
   строка в `SOURCES` → запуск скрипта → `sources: [...]` у загадок + сноска `<sup data-src="id"></sup>` в тексте
   урока после цитаты → русский перевод
   не-Торы в `src/sources/ru.ts`; немецкий — из Sefaria, а где его нет — перевод проекта в `src/sources/de.ts`.
5. Имена Всевышнего: на экране и в печати `אלקים`, `ה׳`, `ה׳ צב-אות`, `א-ל`, «Б-г», G-d, L-rd, G-tt (переводы Sefaria
   правит `scripts/fetch-sources.py`); гиматрия — по настоящему написанию.
6. Новые термины — в `src/i18n/glossary.ts`.
   Транслитерация иврита по-русски: ה в начале и в середине слова — **ґ** (ґа-Турим, Авраґам, Йеґуда, Теґилим, Зоґар,
   артикль «ґа-»); ה на конце не пишется (Тора, Шхина, Моше). ח — «х», как и было.
7. Проверка: `npm run check`, сборка, прохождение урока в браузере (ru/en/de, 390/360 px), PDF печати.
8. Английский и немецкий — по `docs/TRANSLATION-GUIDE.md`: как на chabad.org (en) и de.chabad.org (de) —
   G-d / G-tt, Shabbat / Schabbat, Moshiach / Moschiach, Avraham / Awraham, Chavah / Chawa, Rabbi (не Rabbiner),
   книги на иврите по-немецки (Tehillim, Ijow); немецкий — простой, понятный детям, на «du».
   Запрещённые формы ловит `npm run check` (`scripts/style-rules.ts`).

## «Читать» — урок без счёта

У каждого урока с гиматриями (все, кроме `kind: 'sicha'`) есть пункт меню «Читать» (`#/<slug>/read`,
`src/components/ReadPage.tsx`) — урок для чтения, **по главам** (глава = загадка игры): стих (условие) → разделы урока,
в каждом сначала **слова комментатора в оригинале с переводом** (`Quote`, из `sefaria.json`; какой комментарий в каком
разделе — `quotes` загадки, напр. `['bht-6-9:2']`; каждый комментарий ровно один раз — проверяет `npm run check`), потом
объяснение; выводы проекта — отдельным абзацем `<p class="expl"><b>Пояснение.</b> …</p>` (en «Explanation.», de
«Erklärung.»), чужие объяснения — с именем и сноской («Раши объясняет…»). В конце главы — свёрнутый блок «Как это сходится»
(равенства и готовые ответы шагов с расчётом из `coach`), первоисточники, конспект, вопрос к себе; в конце урока —
«Ґораа ле-поаль» и приглашение сыграть. Карточек слов и вопросов игры на странице нет. Опечатки издания исправляются
в `FIXES` (`scripts/fetch-sources.py`) и помечаются под цитатой. Ссылки: меню (`lessonGames.ts`), кнопка в шапке урока,
строка под условием нерешённой загадки, значок книги на плитке главной. Новый урок попадает туда автоматически.

Слова комментатора (`src/core/quotes.ts`, компонент `Quote.tsx`) показываются **везде, где есть текст раздела**:
в «Читать», в «Урок открыт» игры, в печати и на статической `/<slug>/`. Поэтому **текст раздела не пересказывает цитату**:
в нём — то, чего в цитате нет (расчёт, исходный стих, другие места и источники, несходящиеся гиматрии), и «Пояснение».

**У каждого раздела «Урок открыт» — сноска на источник** (кроме вводных и пересказов-рассуждений статьи — `noSource`
загадки); это проверяет `npm run check`.

## Иврит: уровень игрока

Знать иврит не нужно — нужно узнавать буквы. При первом заходе в начале «Как играть» — вопрос **«Как вы с ивритом?»**
(`HebrewLevelPicker` в `Panels.tsx`, `src/core/hebrewLevel.ts`, только в браузере; меняется в меню «Мой иврит»;
машинам-читателям не задаётся): **«Не знаю букв»** — под каждой буквой её название (`letterHelp.tsx`, `src/core/letterNames.ts`
ru/en/de), на карточках слов — как читается слово (`translit` в тексте урока), подсказка «Собери слово» называет нужные
буквы (в порядке фразы, не ответа), предлагается «Буквы за 5 минут»; **«Узнаю буквы»** (по умолчанию, и если вопрос
пропущен) — название по долгому нажатию / наведению (`title`); **«Читаю на иврите»** — без подсказок. Уровень меняет только
подсказки, не загадки и не очки. «Буквы за 5 минут» (`#/letters`, `LettersPage.tsx`; меню → «Как играть и учиться»: там же «Как играть», «Мой иврит», «Устный счёт»; группы меню изначально свёрнуты) — таблица
22 букв и 5 конечных (вид, название, звучание, число), «Не перепутайте» и тест из 10 вопросов с похожими буквами.
В распечатке таблица букв — всегда с названиями. **У каждого слова на карточках — `translit` на всех языках**
(ru — по правилу ґ; en/de — как chabad.org / de.chabad.org); это проверяет `npm run check`.

## Перевод, режим чтения, «слушать»

- Язык страницы — `<html lang>` (ставит i18n); урок на запасном языке помечает свой блок `lang`.
- Весь иврит (`.he`, `.heb`, `[lang="he"]`) получает `lang="he" translate="no"` — `src/core/langMarkup.ts`
  (на сайте — сам, через MutationObserver; в статических страницах — `markHebrewHtml` в `scripts/prerender.ts`):
  переводчик браузера не трогает слова Торы и Имена, голос читает их как иврит. Новый иврит — просто класс `he`.
- Страницы чтения (`ReadPage`, `CardsReadPage`) — один `<article>` с `h1`, автором (`.author`) и разделами
  `<section>`: так их берут режим чтения браузера (проверено Readability) и «прочитать вслух». Декоративное
  (плитки букв) — `aria-hidden`; не для голоса — класс `no-speak`. `og:title` следует за `document.title` (`pageMeta.ts`).
- Своей кнопки «Слушать» нет — читает браузер («Прослушать страницу» в Chrome). Chrome на Android открывает адрес
  заново на сервере Google (чистый браузер, UA `Google-Read-Aloud`), поэтому: язык всегда в адресе — `?lang=ru`
  (`src/i18n/index.tsx` ставит его сам, `history.replaceState`), а окно «Как играть» при первом заходе не открывается
  для машин-читателей (`isReader` в `App.tsx`). Статическая `/<slug>/` содержит весь пересказ.

## Разрешения браузера — только уведомления, и только по нажатию

Сайт не просит у браузера ни микрофон, ни камеру, ни местоположение, ни распознавание речи:
город для Шабата — по часовому поясу, буфер обмена
и «поделиться» — по нажатию, без запроса. `npm run check` ругается на такие API в `src/`.
**Одно исключение — уведомления** «Напоминать каждый день»: `Notification.requestPermission()` только в
`src/core/push.ts` и только когда игрок нажал «Включить напоминание» (сам сайт никогда не спрашивает).

## «Напоминать каждый день» и офлайн

- **Сообщение дня** (`src/core/dailyMessage.ts`): одно в день из уроков **текущей главы** (первая глава с уроками,
  чей Шабат — в этот день или позже; после последней главы — последняя): загадка ленты «Знаете ли вы?» (только вопрос,
  «Ответ — на сайте»), «Знаете ли вы?» пары Memo, объяснение Ребе с карточки, тезис конспекта, «Ґораа ле-поаль» —
  уроки всех учителей по очереди, виды по очереди. По порядку с воскресенья недели главы; в Шабат сообщения нет.
  `npm run check` проверяет: у каждой главы ≥ 6 сообщений, за неделю ни одно не повторяется, тексты на всех языках.
  `scripts/prerender.ts` пишет расписание на 62 дня — `dist/daily-message.json`.
- **Отправка** — сервер `assistant/` (`src/push.ts`, Durable Object `PushHub` на SQLite, бесплатный тариф): хранит
  только адрес push браузера, часовой пояс, час (7, 8, 13, 16, 17, 19 — `PUSH_HOURS` на сайте и в `assistant/src/rules.ts`)
  и язык; ключи VAPID создаёт сам при первом запуске. Cron раз в час (`wrangler.toml`) — пустой push тем, у кого
  наступил их час и сегодня ещё ничего не было; **в субботу и в пятницу с 12:00 по местному времени — ничего**.
  Пачками по 40 (лимит бесплатного тарифа), остальное — через alarm. 404/410 от сервиса push — подписка удаляется.
  Маршруты: `GET /push/key`, `POST /push/subscribe | unsubscribe | test`; принимаются только адреса настоящих сервисов
  push (FCM, Mozilla, Apple, Windows).
- **Показ** — service worker `public/sw.js`: на push берёт сообщение даты устройства из `/daily-message.json` на языке
  из `src/core/push.ts` (хранится в Cache, меняется вместе с языком сайта), ссылка `?ref=push`. «Проверить» в блоке
  напоминания — push сразу. Блок `DailyReminder.tsx` — в карточке «Гиматрии дня» (всегда), в итоге урока, в окне из меню
  («Напоминать каждый день») и из карточки «Нифлаот на телефоне» на главной;
  на iPhone/iPad — подсказка «На экран Домой» (push в Safari — только у установленного сайта).
- **Офлайн** — тот же `sw.js`: страницы — сначала сеть, без сети — сохранённая копия (Шабат по часам устройства
  работает и офлайн); `/assets/*` (код, стили, шрифты — список вписывает `scripts/prerender.ts`) — сохранены при
  установке; поиск в кэше — `ignoreVary` (сервер отвечает `Vary: Origin`). Регистрация — `src/main.tsx`, только в сборке.
- Проверки: `npm run check` = `scripts/check-lessons.ts` + `scripts/check-push.ts` (подпись VAPID, правила Шабата,
  адреса сервисов push, одинаковые часы на сайте и сервере, заготовки в `sw.js`).

## Гость и аккаунт

- **Гость** — по умолчанию: всё доступно, прогресс только в браузере. Аккаунт — по желанию: `#/account`
  (`AccountPage.tsx`), в шапке — «Войти» / ник (`AccountChip` в `TopBar.tsx`), в меню — «Войти» (пункта «Таблица лидеров» в меню нет — она открывается из профиля).
- **Вход** — 6-значный код на email, без пароля (`src/core/account.ts` ↔ `assistant/src/accounts.ts`, Durable Object
  `Accounts` на SQLite; письма — Resend, secret `RESEND_API_KEY`, отправитель `MAIL_FROM`). Без ключа `/account/config`
  отвечает `mail: false` — «Войти» не показывается. Коды (10 мин, 5 попыток, не чаще раза в минуту и 5 в час) и
  токены сессий (180 дней) — только SHA-256. Локально: `wrangler dev --var DEV_CODES:1` — код пишется в лог.
- **Профиль:** ник (3–20 букв/цифр, уникальный; не настоящее имя), возраст «14+ / младше 14» — выбирается один раз;
  младше 14 — email родителя, письмо со ссылкой `#/consent/<token>` («Разрешаю», POST — не GET, чтобы почтовые сканеры
  не подтверждали сами). До согласия аккаунт «ждёт»: прогресс не синхронизируется, нет в таблицах и классах; через
  30 дней без согласия удаляется (alarm раз в сутки). Галочка «показывать в общей таблице лидеров», согласие с `#/privacy`.
- **Синхронизация** (`src/core/sync.ts`): ключи `niflaot:lesson:*`, `niflaot:daily`, `niflaot:hebrew`, `niflaot:lang`,
  `niflaot:math-level`; при входе — слияние (урок — копия с бо́льшим числом решённых, «Гиматрия дня» — все дни обеих
  копий, настройки — этого устройства), потом раз в 30 с и при скрытии страницы. Проверка — `scripts/check-accounts.ts`.
- **Таблица лидеров** `#/leaders[/<класс>]` (`CommunityPages.tsx`): очки, серия и дни «Гиматрии дня», топ-20, только ники.
- **Классы:** создаёт взрослый (14+), код из 6 символов; ученики — «Вступить» по коду; учитель — `#/class/<id>`
  (ник, загадки по урокам, очки, серия, когда обновлялось; «Убрать»).
- **ИИ-учитель:** `/chat` с токеном считает вопросы аккаунта по дням (видно в профиле) — основа для будущей оплаты;
  оплаты пока нет.
- **Конфиденциальность** — `#/privacy` (ru/en/de), ссылка в подвале. «Удалить аккаунт» удаляет всё на сервере
  (прогресс на устройстве остаётся).

## «Знаете ли вы?» — лента загадок

Пункт меню «Знаете ли вы?» (`#/facts`, `src/components/FactsPage.tsx`, данные — `src/core/facts.ts`): все равенства
и буквенные намёки уроков с гиматриями лентой, **без объяснений** — вопрос «А вы знаете, чему равно …?» / «какое слово
спрятано в первых (последних) буквах …?», ответ по нажатию и ссылки **на то место в уроке**: «Где это в уроке:
загадка N» (`#/<slug>/read/N` — чтение, открывается на загадке), «Разгадать самому» (`#/<slug>/r/N` — игра на этой
загадке), «В Memo-игре: пара N» (`#/<slug>/memo/N` — «Изучите пары» на этой паре).
«📤 Поделиться загадкой» — картинка 1080×1350 (`renderFactCard` в `src/core/shareCard.ts`): загадка (вопрос, иврит
с переводом) и под чертой «Ответ» — ответ с переводом; «Почему так — на сайте», подпись niflaot.mychitas.app;
к картинке — текст (загадка, ответ) со ссылкой
`#/facts/<id>` (лента открывается на этой карточке; id постоянный — от слов загадки).
Ответ — **без расчётов**: только число и равные ему слова/выражения, в столбик («האדם ? = 50 = אדמה»); суммы чисел
(«456 + 15») не показываются; равенства одной загадки с тем же числом — одна карточка («פרצוף + גאוה = 471 = זנב + תאוה»).
Собирается само: пары Memo, `equations` загадок (только чистые равенства гиматрий — каждая часть проверяется кодом),
шаги «Собери слово»; повторы убираются. Каждое ивритское слово ленты должно иметь перевод в `glossary` урока
на всех языках, и у каждого факта есть место в уроке (загадка или пара Memo) — это проверяет `npm run check`.

## «Нифлаот Ребе»

В каждой главе — пункт меню и раздел на главной «Нифлаот Ребе» (`#/rebbe/<parsha>`, «Чудеса Торы в учении Ребе»),
**без гиматрий**. Урок раздела — `series: 'rebbe'`, `kind: 'sicha'`; две игры: «Расследование» (`#/<slug>`) и «Карточки»
(`#/<slug>/cards`, стих ↔ одно объяснение Ребе на стих); в меню — сразу под «Нифлаот Ребе»: «<название урока>»
(расследование), «Карточки» и «Прочитать» (`#/<slug>/read`, `CardsReadPage.tsx`) — все пары «стих — объяснение
Ребе» подряд, с переключателем «📖 Прочитать / 🎵 Запомнить в стихах» (`#/<slug>/read/poem`): у каждой пары
`poem` в `cards.items` — 4–6 рифмованных строк на каждом языке (стих, объяснение, вывод — ничего от себя), это проверяет
`npm run check`. Подробно — `docs/LESSON-GUIDE.md`.

## Правило: у урока-комментария — две игры

У урока по комментарию (`kind: 'commentary'`, Бааль ґа-Турим) **два подменю, равноправных и доступных в любой момент**:
«Игра с гиматриями» (`#/<slug>`, загадки) и «Memo-игра» (`#/<slug>/memo`). Обе игры — подпунктами урока в меню
(`lessonGames.ts`) и на карточке урока на главной; переключателя под шапкой урока нет (он дублировал меню);
в итоге гиматрий — приглашение в Memo.
- Языки игры — языки сайта (ru, en, de). Иврит — только слова Торы и цитаты комментария, всегда с переводом.
  Отдельного ивритского интерфейса пока нет.
- Методика Memo: «Изучите пары» → лёгкая игра (6 пар) → полная (12) → «Что мы узнали». На карточках-картинках подписей нет;
  под игрой — список «Что на картинках» (`title` + `caption`: что изображено и что это значит) — он связывает картинку
  со словами Торы. Карточка слов — иврит + перевод. После пары — «Бааль ґа-Турим пишет» (иврит + перевод), «Знаете ли вы?», гиматрия/игра букв с расчётом,
  «Чему это учит?».

## Правило: в Шабат сайт отдыхает

За час до захода солнца в пятницу и до часа после захода в субботу (с запасом в обе стороны) **для города
пользователя** вместо сайта — экран «Шабат шалом» и время, когда сайт откроется (`src/core/shabbat.ts`, `zmanim.ts`,
`places.ts`, `src/components/ShabbatRest.tsx`). **Ґалахических времён и слов на сайте нет** («зажигание свечей»,
«исход Шабата» не показываем — это ответственность общины). Город — по часовому поясу устройства (без запроса
геолокации); пояс не из списка или нет захода солнца — с 14:00 пятницы до 23:00 субботы по часам устройства.
Сайт закрывается и открывается сам (проверка раз в 30 с). Таймер «Осталось играть на этой неделе» на главной считает
до того же момента.
Посмотреть экран в любое время: `?shabbat=preview`.
