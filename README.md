# Нифлаот · Niflaot

**Сайт: https://niflaot.mychitas.app**

**Нифлаот** — «чудеса». Онлайн-академия Торы «от 8 до 120»: чудеса Торы глазами разных учителей, Пророки и Писания
каждый день, Хасидут, иврит Танаха по словам — и сертификаты за пройденные книги. Тора-проект [MyChitas](https://mychitas.app).

Общее для всего сайта: ответ не дают готовым. Ученик находит его сам, шаг за шагом, и только потом открывает,
что за ним стоит: **загадка → поиск → смысл → урок → вывод для жизни.**

**Коротко о главном:** бесплатно и без рекламы; иврит знать не нужно (буквы — за 5 минут прямо на сайте); на любой
вопрос по странице сразу ответит ИИ-учитель, «подсказывая, а не раскрывая»; гостем доступно всё, аккаунт — по желанию;
три языка — русский, английский, немецкий; на телефоне (как приложение и в Telegram), в классе и на бумаге;
каждую неделю — уроки к недельной главе, каждый учебный день — отрывок Пророков и Писаний и отрывок Хасидута;
в Шабат сайт отдыхает.

## Два режима — одна академия

При первом заходе сайт спрашивает: **«Кто будет учиться?»** и **«Как вы с ивритом?»** — и никогда не показывает оба
режима сразу (сменить — в окне аккаунта 👤).

|---|---|---|

тексты из общественного достояния или под открытой лицензией (и пересказы бесед Ребе); тексты, на которые нет
письменного разрешения правообладателя, с сайта убраны.

Каждое число в уроках проверено кодом: гематрия, которая не сходится, в урок не попадает (а в тексте честно сказано,
что она не сходится). Пересказ — без добавлений от имени автора, выводы проекта подписаны «Пояснение».

### Что внутри урока

- **Загадки по шагам** — у каждого шага время и сложность. В гематрийных уроках: карточки слов на иврите
  (нажмите — увидите буквы и их значения, сложите сами), буквенные загадки в духе Бааль ґа-Турим
  (ראשי / סופי תיבות, нотарикон, перестановка букв) и разбор «Посчитать вместе».
  В уроках Ребе — расследование: сравнить стихи, выбрать ответ, открыть объяснение Ребе.
- **Урок открыт.** После решения — полный пересказ по разделам, слова комментатора в оригинале с переводом,
  сноска на источник в каждом разделе и вопрос к себе.
- **«Читать» — урок без счёта.** Весь урок по главам: стих → слова комментатора → объяснение; расчёты свёрнуты
  в конце главы. В конце главы — **«Проверь себя»** (засчитывается в сертификат Торы «чтением»). У уроков Ребе —
  «Прочитать»: «📜 Беседа», «🃏 Карточки» и **«🎵 Запомнить в стихах»** — каждая пара рифмованными строками.
- **Конспект и «Ґораа ле-поаль»** — главные тезисы и один практический вывод.
- **Вторая игра:** Memo (24 карты-раскраски, 12 пар: «Изучите пары» → 6 пар → 12 пар → «Что мы узнали»)
  или «Карточки» (стихи главы ↔ объяснения Ребе); после каждой пары — объяснение и вывод.
- **Первоисточники** — стихи, Талмуд, мидраши, комментарии: иврит и перевод рядом, ссылка на Sefaria, сноски в тексте.
- **Печать** для стола, класса и Шабата: рабочий лист с ответами для учителя, карточки Memo и «стих — объяснение» для
  вырезания. В шапке — логотипы проекта и партнёров, недельная глава, дата Шабата и QR-код на урок.
- **Поделиться** — картинка с главной мыслью урока и текст для WhatsApp и Telegram.

## Пророки и Писания — трёхлетний цикл

- **Весь Танах (кроме Торы) за три года:** с 11.10.2026 до Симхат Тора 5790 — 898 учебных дней, без Шабата и
  праздников; каждый день — отрывок Пророков и отрывок Писаний (≈ 10–15 минут).
- По стиху: **иврит с огласовками**, перевод и классические комментарии **Мецудат Давид** (простой смысл) и **Раши**.
  Вид — «Иврит и русский / English», «Только перевод», «Только иврит»; «≈ N мин чтения»; печать дня (в Telegram-канал
  каждое утро приходит и PDF дня).
- **Переводы проекта** стиха и комментариев на ru/en/de — с ивритского оригинала, в еврейском стиле (Б-г, Машиах,
  Йерушалаим…); готовы заранее, неделя за неделей.
- **«Вопросы к отрывку»** — 3–4 вопроса на стихи дня; галочка **«Я прочитал(а)»**, трекер прочитанного и
  **сертификат за книгу** (с баллами или без).
- Страницы для поиска [/neviim/](https://niflaot.mychitas.app/neviim/) и [/ketuvim/](https://niflaot.mychitas.app/ketuvim/) — план цикла и таблица книг.

## «Слова отрывка» и «Иврит Танаха»

- **1000 самых частых слов Пророков и Писаний** дают 89 % текста (500 — 80 %). Под каждым отрывком дня — «Вы узнаёте
  N % слов этого отрывка» и до 5 новых частых слов с переводом и корнем: «Учу» / «Знаю».
- **«Мои слова»** — интервальное повторение («карточки с коробками»: 1, 3, 7, 21, 60 дней), «повторить сегодня»,
  уровни по 50 слов, вехи 100 / 300 / 500 / 1000. Сертификаты «Знаток иврита Танаха» — только за слова, **подтверждённые
  повторением**, а не за отметки.
- Переводы — проекта, **по простому смыслу стиха в еврейской традиции** (Раши, Мецудат Давид), а не по христианским
  словарям; корни — по словарю Брауна — Драйвера — Бриггса с фильтром. Леммы — Open Scriptures Hebrew Bible (CC BY 4.0).
- Детям — **«Слова Торы»**: колода сама собирается из уроков (слова Memo и карточек загадок), игра на 10 вопросов,
  звёздочки, сертификат «Знаток слов главы».
- Страница для поиска [/hebrew-words/](https://niflaot.mychitas.app/hebrew-words/) — «500 слов Танаха — 80 % текста».

Отрывок дня (до 10 минут) с 18.10.2026: название, «Коротко», текст, 3–4 вопроса, «Я прочитал(а)» и сертификат

## «Академия» — сертификаты

Порог — 70 %. Сертификаты Торы (по учителю и книге — за игру или за чтение), книг Пророков и Писаний, маамаров

датой (гражданской и еврейской), QR-кодом, логотипами партнёров и подписью ректора; «Распечатать / сохранить PDF».

## И ещё на сайте

- **«Знаете ли вы?»** — лента всех загадок уроков без объяснений: ответ — по нажатию, объяснение — ссылкой на то место
  в уроке. Любую загадку можно отправить картинкой 1080×1350 («📤 Поделиться загадкой»).
- **«Гематрия дня»** — первая карточка ленты: каждый день одно слово, сумму букв считают в уме, 3 попытки.
  Результат — цветные квадратики без ответа (🟥🟩 · ⏱ · 🔥 серия; Шабат серию не рвёт), как Wordle.
- **«Как вы с ивритом?»** — «Не знаю букв» (под каждой буквой — её название, у слов — как читается), «Узнаю буквы»,
  «Читаю на иврите». **«Буквы за 5 минут»** — таблица 22 букв и 5 конечных, «Не перепутайте» и тест.
- **Устный счёт** — приёмы и тренажёр на числах из уроков; **калькулятор гематрии** — слово всеми способами счёта.
- **ИИ-учитель ✦** (Claude) — видит, что открыто на экране (урок, отрывок, вопросы, «Мои слова»), отвечает на ru/en/de,
  считает гематрию тем же кодом, что сайт, и **не может раскрыть ответ**: ответы нерешённых загадок и верные варианты
  неотвеченных вопросов ему не передаются. «ИИ — не раввин». Пункт «Учитель» — ИИ или письмо живому учителю.
- **Словарь терминов** — по нажатию на слово; **Имена Всевышнего** — с уважением (אלקים, ה׳, «Б-г», G-d, G-tt),
  гематрия — по настоящему написанию.
- **Читается браузером вслух и в режиме чтения**: иврит помечен как иврит — переводчик не трогает слова Торы.
- **Как приложение:** «Установить на телефон» (Android, компьютер) или «На экран Домой» (iPhone); **Telegram Mini App**;
  **работает без интернета** — открытые страницы сохраняются.
- **«Напоминать каждый день»** — одно уведомление в выбранный час: детям — загадка или мысль из уроков недельной главы,
  взрослым — отрывок дня и слова к повторению; в Шабат и в пятницу после полудня — ничего.
- **Гость или аккаунт.** Гостем доступно всё. Аккаунт (вход по 6-значному коду на email, без пароля) — прогресс на всех
  устройствах; детям до 14 — согласие родителя по ссылке в письме.
- **Приватно:** без cookies; из разрешений браузера — только уведомления и только по нажатию. Статистика — GoatCounter
  без cookies. Вопросы ИИ-учителю уходят в Anthropic (Claude) — об этом сказано под чатом.
- **В Шабат сайт отдыхает**: за час до захода солнца в пятницу и до часа после захода в субботу в городе
  пользователя — «Шабат шалом» и время, когда сайт откроется (посмотреть: `?shabbat=preview`).
- **Партнёры** — [Chabad Haus Wien](https://chabadvienna.com) и [JRCV Vienna](https://jrcvienna.com).

## Конкурентоспособность и новизна

Оценка на октябрь 2026 г., по сравнению с тем, что уже есть в еврейском онлайн-обучении.

### С кем сравнивать

| Кто | Сильная сторона | Чего у них нет по сравнению с Нифлаот |
|---|---|---|
| **Sefaria** | огромная открытая библиотека, связи между текстами | это библиотека, а не путь: нет игр, заданий, ежедневного плана с проверкой, сертификатов, русского и немецкого переводов комментариев |
| **Chabad.org** (в т. ч. de./ru.) | ежедневные уроки (Хитас, Рамбам), огромный архив, авторитет | тексты и видео без интерактива; нет проверки себя, интервального повторения слов, игр для детей по главе недели |
| **929** и программы «глава в день» | общий ритм чтения Танаха | одна глава в день без классических комментариев на ru/de, без вопросов к стихам и сертификатов |
| Приложения Даф йоми, TorahAnytime | ежедневное обучение, лекции | аудио/видео, взрослая аудитория; ни детского режима, ни игры |
| Детские сайты (JewishKids.org, Torah Live и т. п.) | истории, мультфильмы, раскраски | готовые ответы, а не «найди сам»; нет первоисточников в оригинале и пути до взрослого учения |
| Duolingo / приложения иврита | отличная механика повторения | современный иврит; не язык Танаха, нет связи с ежедневным чтением |
| Колоды Anki «Biblical Hebrew» | частотные слова | протестантские словари, английский, нет связи с текстом дня и с еврейским пониманием слова |

### Что действительно ново

1. **Игра, в которой ответ находят сами, — на настоящих комментаторах.** Гематрии и буквенные приёмы Бааль ґа-Турима
   превращены в пошаговые загадки, расследования — на беседах Ребе; каждое число проверено кодом, у каждого раздела —
   первоисточник. Подобного сочетания «игра + первоисточник + проверка кодом» у известных проектов нет.
2. **Одна академия «от 8 до 120» с двумя режимами.** Ребёнок и взрослый учат одну и ту же главу недели: ребёнок — играя,
   взрослый — читая; дальше взрослого ведёт трёхлетний цикл Пророков и Писаний. Семья учит вместе, но каждый — своё.
3. **Иврит Танаха через ежедневное чтение.** «Вы узнаёте N % слов этого отрывка» + частотный словарь + интервальное
   повторение, причём **по еврейскому пониманию слова** (Раши, Мецудат Давид). Сертификат — только за слова,
   подтверждённые повторением. Это редкость даже на английском, а на русском и немецком аналогов практически нет.
4. **ИИ-учитель, который не может подсказать ответ.** Он видит страницу, но ответы ему не передаются — честная
   помощь без списывания; гематрию считает инструментом, а не «в уме».
5. **Уважение к Шабату и приватности как часть продукта:** сайт сам закрывается в Шабат по городу пользователя,
   без cookies, без лишних разрешений, гость может всё.
6. **Ниша языков:** русский и немецкий — с переводами проекта Мецудат Давид, Раши и Хасидута; для русско- и
   немецкоязычных общин (Вена, Германия, бывший СССР) это почти пустое место.

### Сильные стороны

- **Качество и честность контента** — автоматические проверки (`npm run check`): числа, Имена, стиль переводов,
  лицензии, полнота переводов, отсутствие закрытых текстов.
- **Готовый ежедневный ритм:** отрывок дня, «Гематрия дня», Хасидут, напоминания, Telegram-канал с PDF —
  то, что возвращает человека каждый день.
- **Всё бесплатно и работает везде:** сайт, приложение на телефоне, Telegram Mini App, офлайн, печать для класса
  с QR-кодом, SEO-страницы на трёх языках.
- **Низкая стоимость содержания:** статический сайт на GitHub Pages и бесплатные тарифы Cloudflare; платный только ИИ
  (с лимитами расходов).

### Слабые стороны и риски

- **Мало уроков Торы** — пока 6 уроков в трёх главах; ценность детского режима растёт только с регулярным выпуском
  новых уроков (по 2 в неделю — серьёзная нагрузка).
- **Узкий круг авторов-учителей** и зависимость от разрешений: тексты без открытой лицензии публиковать нельзя,
  Хасидут — по разрешению Neirot.
- **Словарь и переводы раввином пока не проверены** — для части аудитории это вопрос доверия; нужна подпись
  ответственного раввина.
- **Узнаваемость:** у Sefaria и Chabad.org — миллионы посетителей; у Нифлаот — только партнёрские общины, канал и
  поиск. Без сарафанного радио и учителей в классах рост будет медленным.
- **Нет интерфейса на иврите** и (пока) на других языках; нет нативных приложений в магазинах; аккаунты зависят от
  почтового сервиса.
- **Один разработчик** и большой объём ручной подготовки (переводы на три языка заранее, вопросы к каждому дню).

## Разработка

React 19 + TypeScript + Vite, статический сайт (GitHub Pages) + сервер `assistant/` на Cloudflare Workers
(ИИ-учитель, напоминания, аккаунты).

```bash
npm install
npm run dev      # локальный сервер
npm run check    # проверка: уроки, гематрия, источники, Танах, слова, Хасидут, академия, push, аккаунты, безопасный HTML
npm run build    # tsc + vite + scripts/prerender.ts → dist/
```

## Как добавить урок

Полный порядок — в **[docs/LESSON-GUIDE.md](docs/LESSON-GUIDE.md)** (обязателен для каждого урока):
полный пересказ, проверка всех чисел кодом, конспект и практический вывод, первоисточники из Sefaria,
Имена Всевышнего, переводы по [docs/TRANSLATION-GUIDE.md](docs/TRANSLATION-GUIDE.md), проверка в браузере.

```bash
npm run check
npm i --no-save playwright && npx tsx scripts/og-images.ts   # картинка превью public/og/<slug>.png
```

Страница `/<slug>/`, `sitemap.xml`, ленты Atom, «Читать», «Проверь себя», лента «Знаете ли вы?», «Гематрия дня»,
«Слова Торы» и сообщения напоминаний подхватят урок сами.

## Безопасность и приватность

- Content-Security-Policy на каждой странице: скрипты и шрифты — только с самого сайта (и счётчик GoatCounter).
- Из разрешений браузера — только уведомления и только по нажатию; `npm run check` следит за этим.
- Тексты с разметкой проходят allowlist-санитайзер; `<script>`, `on…=` и `javascript:` не пропускаются.
- Ключ Claude API — только на сервере. Лимиты: 6 вопросов в минуту с IP и 1000 в сутки на всех; лимит расходов —
  platform.claude.com → Billing.
- Коды входа и токены хранятся только как SHA-256; «Удалить аккаунт» удаляет всё на сервере.

`TELEGRAM_APP`; рассылка — variable `SUBSCRIBE_URL`.

`src/content/overrides.json` в `main`.
