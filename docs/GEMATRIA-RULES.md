# Правила гиматрии и буквенных приёмов

Комментаторы Торы — Бааль ґа-Турим, Ари, хасидут — считают слова не одним способом. Здесь — все способы,
которые поддерживает проект: что это, как считается, как записать в данных урока и как проверяется.
Код — `src/core/gematriaMethods.ts` (способы счёта) и `src/core/letterPuzzle.ts` (буквенные приёмы);
примеры из таблиц ниже проверяет `npm run check` (`METHOD_EXAMPLES`).

**Главное правило проекта не меняется:** число, которое не сходится ни одним из способов, в урок не попадает.
Если комментатор пишет просто «гиматрия», а сходится только другим способом (например, «с колелем»),
в тексте урока это говорится прямо: «Бааль ґа-Турим пишет „гиматрия“, а сходится по правилу колеля».
Способ подбирать «под ответ» нельзя: берём тот, который принят у комментаторов и даёт ровно их числа.

## 1. Способы счёта (числовые)

| Способ | Иврит | Правило | Пример (проверен) | В данных |
|---|---|---|---|---|
| Обычная гиматрия | מספר הכרחי | א = 1 … ט = 9, י = 10 … צ = 90, ק = 100 … ת = 400; конечные ך ם ן ף ץ = обычным | חמס = 108 = מי נח | по умолчанию |
| Большое число | מספר גדול | конечные буквы продолжают счёт: ך 500, ם 600, ן 700, ף 800, ץ 900 | אדם = 605 | `method: 'gadol'` |
| Малая гиматрия | מספר קטן | значение буквы без нулей: י = 1, כ = 2 … ק = 1 … ת = 4 | נח = 5 + 8 = 13 | `method: 'katan'` |
| Порядковое число | מספר סידורי | место буквы в алфавите: א = 1 … ת = 22 | נח = 14 + 8 = 22 | `method: 'siduri'` |
| Накопленное число | מספר הכדמי | сумма всех букв от א до этой: א 1, ב 3, ג 6, ד 10 … | אב = 1 + 3 = 4 | `method: 'kadmi'` |
| Полное написание | מילוי | каждая буква — своим именем: א = אלף = 111 | אש = אלף + שין = 471 | `method: 'milui'` |
| Скрытая часть | נעלם | имя буквы без неё самой: אלף − א = לף = 110 | אש = 110 + 60 = 170 | `method: 'neelam'` |
| С колелем | עם הכולל | +1 за само слово как целое (иногда + число слов или букв) | שפה אחת = 794 + 1 = 795 = לשון הקדש | в `coach`: `{ add: ['$N', 1] }` |
| Сумма цифр | מספר קטן מספרי | цифры числа складывают, пока не останется одна | אמת = 441 → 9 | в `coach`: числами |
| «Квадрат» | ריבוע | сумма растущих начал слова | אמת = א + אמ + אמת = 483 | в `coach`: `{ word }` для каждого начала + `add` |

Полное написание букв с несколькими вариантами имени — по `LETTER_NAMES` в `src/core/gematria.ts`
(ה → הא, ו → וו, פ → פא, צ → צדי). Если комментатор пишет иначе (например, ה = הה), значение считается
вручную в `coach` и написание называется в тексте урока.

## 2. Замены букв (צירופי אותיות)

Слово сначала переписывается другими буквами, потом новое слово считается обычной гиматрией.

| Способ | Иврит | Правило | Пример (проверен) | В данных |
|---|---|---|---|---|
| Атбаш | א״ת ב״ש | алфавит «в зеркало»: א ↔ ת, ב ↔ ש, ג ↔ ר, ד ↔ ק … | שרה → בגץ = 95 = יסכה (Бааль ґа-Турим, Берешит 11:29) | `method: 'atbash'` |
| Альбам | א״ל ב״ם | алфавит пополам: א ↔ ל, ב ↔ מ, ג ↔ נ … כ ↔ ת | אב → למ = 70 | `method: 'albam'` |
| Аик бехар | אי״ק בכ״ר | буквы с одной «малой гиматрией» взаимозаменяемы (א י ק, ב כ ר, ג ל ש …) | — | объяснить в тексте |

## 3. Буквенные приёмы

| Приём | Иврит | Что это | Шаг игры |
|---|---|---|---|
| Рашей тевот | ראשי תיבות (ר״ת) | первые буквы соседних слов составляют слово: משחיתם את הארץ → מאה | `lt`, `take: 'first'` |
| Софей тевот | סופי תיבות (ס״ת) | последние буквы: בראשית ברא אלקים → אמת | `lt`, `take: 'last'` |
| Нотарикон | נוטריקון | каждая буква **одного** слова начинает отдельное слово: בראשית = בראשונה ראה אלקים שיקבלו ישראל תורה; אדם = אפר דם מרה | `ch` с `notarikon: 'בראשית'` |
| Те же буквы | אותיות / צירוף | перестановка всех букв: ויתגל = גליות, בהבראם = באברהם | `lt`, `take: 'all'` |
| Полное и неполное написание | מלא וחסר | в Торе не хватает буквы или есть лишняя: מארת без ו | `tap` с `written` |
| Пары по масоре | ב׳ / ג׳ במסורה | слово встречается в Танахе ровно 2–3 раза, места объясняют друг друга | в тексте урока |
| Соседство | סמיכות (דסמיכי) | два выражения стоят рядом — значит, связаны | в тексте урока |

Рашей тевот и нотарикон — разные приёмы: в рашей тевот из **фразы** получается слово (фраза → слово),
в нотариконе **слово** раскрывается во фразу (слово → фраза). Для шага-нотарикона варианты ответа — фразы;
`npm run check` требует, чтобы первые буквы слов подходили ровно у одного варианта — правильного.
После выбора у каждого варианта показываются его первые буквы.

## 4. Как записать в урок

```ts
// число другим способом: «Посчитать вместе» покажет буквы и их значения в этом способе
{ t: 'num', a: 95, coach: [{ word: 'שרה', method: 'atbash' }] }          // ש→ב 2 + ר→ג 3 + ה→צ 90
{ t: 'num', a: 13, coach: [{ word: 'נח', method: 'katan' }] }            // נ 5 + ח 8
// колель — отдельным действием, чтобы игрок видел «+1»
{ t: 'num', a: 795, coach: [{ word: 'שפה' }, { word: 'אחת' }, { add: ['$1', '$2'] }, { add: ['$3', 1] }] }
// значения вариантов выбора в другом способе (проверяются этим способом)
{ t: 'ch', method: 'milui', opts: [{ h: 'אש', v: 471 }, …], c: 0 }
// нотарикон
{ t: 'ch', notarikon: 'בראשית', opts: [{ h: 'בראשונה ראה אלקים שיקבלו ישראל תורה' }, …], c: 0 }
```

- В условии загадки способ **называется и объясняется** до шага (что такое атбаш, что такое колель) —
  игрок не должен угадывать правило.
- В `equations` — без ивритских пояснений в скобках (они путают направление строки): `'שפה אחת = 794'`,
  `'794 + 1 = 795 = לשון הקדש'`, `'שרה → א״ת ב״ש → בגץ'`; способ называется в разгадке и в тексте урока.
- В HTML-текстах стрелки между ивритскими буквами — **вне** `<span class="he">`: `<span class="he">ש</span> → <span class="he">ב</span>`,
  иначе браузер переворачивает «ש → ב» в «ב ← ש».
  В ленту «Знаете ли вы?» попадают только чистые равенства обычной гиматрии (`'בגץ = 95 = יסכה'`).
- Новые слова способа (בגץ и т. п.) — в `glossary` урока на всех языках, как и все слова ленты.
- Калькулятор гиматрии показывает любое слово всеми способами (раскрывающийся список «Другие способы счёта»),
  названия и правила — ключи `method.*` в `src/i18n/locales/*.ts`.

## 5. Новый способ

1. Добавить его в `Method` и `letterValue` в `src/core/gematriaMethods.ts` (или отдельной функцией, как `withKolel`).
2. Пример с проверенным числом — в `METHOD_EXAMPLES`; строку — в таблицу выше.
3. Название и правило — `method.<имя>` и `method.<имя>.rule` в `src/i18n/locales/ru.ts`, `en.ts`, `de.ts`.
4. `npm run check`.
