# Свои фоны для «Картины со стихом»

Раздел «Стих твоего имени — картина» (только 16+) умеет брать не только фоны, нарисованные кодом, но и твои картины.
**Ты рисуешь фон без текста, а игра сама ставит на него стих** нужной пары букв (шрифтом, из списка «Тора Эмет»),
ссылку на книгу, имя (если человек этого хочет) и подпись сайта. Поэтому один фон подходит сразу к сотням стихов,
а в огласовке не бывает ошибок, которые делают генераторы картинок.

## 1. Нарисуй фон

- **Без букв, цифр и надписей** — ни на иврите, ни на других языках.
- Оставь спокойное, тёмное место для текста: по умолчанию это полоса посередине
  (телефон и A4 — примерно от 33 % до 64 % высоты, компьютер — от 25 % до 70 %).
  Текст золотой, поэтому фон под ним лучше тёмный.
- Главное держи ближе к центру: если пропорции не совпадут точно, края обрежутся.
- Размеры (можно больше, меньше половины не пройдёт проверку):

  | Формат | Файл | Размер |
  |---|---|---|
  | Телефон | `phone` | 1170 × 2532 (вертикальный, 9 : 19,5) |
  | Компьютер | `screen` | 3840 × 2160 (горизонтальный, 16 : 9) |
  | Печать A4 | `print` | 2480 × 3508 (вертикальный, A4 при 300 dpi) |

- Формат файла `.jpg`, `.png` или `.webp`, имя латиницей без пробелов (`deep-waters-phone.jpg`), **не больше 4 МБ**
  (сожми, например, на squoosh.app: JPEG, качество 80–85).
- Не обязательно делать все три: игра предложит только те форматы, для которых есть файл.
- Используй только свои картины или те, на которые у проекта есть право. Если рисуешь генератором — проверь,
  что его условия разрешают такое использование.

## 2. Загрузи в репозиторий

На GitHub: репозиторий → папка `gallery` → **Add file → Upload files** → перетащи файлы → **Commit changes**
(лучше в новую ветку и через Pull Request, чтобы перед публикацией прошли проверки).

## 3. Впиши фон в `gallery/backgrounds.json`

Открой файл на GitHub (карандаш «Edit») и добавь сюжет в список `scenes`:

```json
{
  "scenes": [
    {
      "id": "deep-waters",
      "name": {"ru": "Глубокие воды", "uk": "Глибокі води", "de": "Tiefe Wasser", "en": "Deep waters"},
      "files": {"phone": "deep-waters-phone.jpg", "screen": "deep-waters-screen.jpg", "print": "deep-waters-a4.jpg"}
    }
  ]
}
```

Обязательно:

- `id` — короткое имя латиницей (`a-z`, цифры, `-`), у каждого сюжета своё; `deep`, `night`, `dawn` заняты.
- `name` — название кнопки на четырёх языках.
- `files` — хотя бы один из `phone`, `screen`, `print`.

По желанию:

- `"pairs": ["מה", "אה"]` — фон только для этих пар букв (первая и последняя буква имени, без конечных форм:
  `מ`, а не `ם`). Так можно сделать картину к конкретному стиху: например, «Глубокие воды» к Мишлей 20:5.
  Без `pairs` фон предлагается для любого имени.
- `"band": {"phone": [0.4, 0.7]}` — где стоит текст: верх и низ полосы в долях высоты (0 — верх, 1 — низ) для каждого формата.
- `"shade": 0.35` — насколько затемнить фон под текстом (0 — не затемнять, 1 — чёрный). По умолчанию 0.35.
- `"frame": false` — не рисовать золотую рамку на листе A4 (если в твоей картине своя рамка).

Между сюжетами ставится запятая. Свои сюжеты стоят в списке первыми, перед нарисованными кодом.

## 4. Проверь

- `npm run test:data` проверит файл: есть ли картинки, их размер и вес, названия на всех языках, буквы в `pairs`.
  Эту же проверку запускает Pull Request.
- `npm start` → http://localhost:8080 → создай героя 16+ → меню «Твоя часть в Торе» → «Картина со стихом».
  Проверь, что текст читается на всех трёх форматах. Если нет — сдвинь `band` или увеличь `shade`.
- Покажи раву готовые картины с текстом, прежде чем публиковать.

После слияния в `main` сайт обновится сам (GitHub Pages).
