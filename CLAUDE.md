# Niflaot — память проекта

«Нифлаот» — чудеса Торы глазами разных учителей (Тора-проект MyChitas). У каждого автора свой жанр урока:
рав Ицхак Гинзбург (статьи брошюры «Нифлаот») — игры-гиматрии; Бааль ґа-Турим (комментарий) — гиматрии и буквы + Memo;
Любавичский Ребе (беседы «Ликутей сихот», раздел «Нифлаот Ребе») — расследование без гиматрий + карточки.
Общее: игрок сам находит ответ, потом — пересказ, первоисточники Sefaria, вывод для жизни, печать; ru/en/de.
Уроки сгруппированы по недельным главам. Сайт: https://niflaot.mychitas.app
(GitHub Pages, публикация через `.github/workflows/deploy.yml` при пуше в `main`).
Общаться с владельцем проекта — по-русски.

## Стек и команды

- React 19 + TypeScript + Vite, hash-роутинг (`#/`, `#/<slug>`, `#/<slug>/print`, `#/math/<op>`);
  статические `/<slug>/` (SEO) открывают тот же урок.
- `npm install`, `npm run dev`, `npm run build` (tsc + vite + prerender), `npm run check` (проверка данных уроков).
- Браузерные проверки: Playwright + Chromium из `/opt/pw-browsers` (не скачивать браузер).

## Новый урок — всегда по `docs/LESSON-GUIDE.md`

Обязательно для каждого урока:
1. Полный пересказ статьи по разделам (ru + en + de), без добавлений от имени рава.
2. Каждое число и каждый вариант ответа проверены кодом; не сходится — не включать.
   У каждого числового шага — разбор `coach` для модуля `src/core/coach.ts` (слова и числа,
   не строки), его итог = ответ шага. Проверка всего этого — `npm run check` (он же запрещает в HTML-текстах `<script>`, `on…=` и `javascript:`).
   Карточки слов не подсказывают ответ; каждое ивритское слово на экране объяснено (что значит, при чём здесь).
3. Поля: вопрос к себе, тезисы конспекта (`takeaways`), «Ґораа ле-поаль» (`practice`),
   равенство для картинки (`highlight`), текст «поделиться» со всеми загадками,
   пазл «Собери смысл» (`puzzle`) у каждой загадки и итоговый у урока — только в последовательных статьях
   рава Гинзбурга; у уроков-комментариев (`kind: 'commentary'`, Бааль ґа-Турим и т. п.) пазлов нет.
4. **Первоисточники из Sefaria** для всех цитируемых текстов: `scripts/fetch-sources.py ls/find` →
   строка в `SOURCES` → запуск скрипта → `sources: [...]` у загадок + сноска `<sup data-src="id"></sup>` в тексте
   урока после цитаты → русский перевод
   не-Торы в `src/sources/ru.ts`; немецкий — из Sefaria, а где его нет — перевод проекта в `src/sources/de.ts`.
5. Имена Всевышнего: на экране и в печати `אלקים`, `ה׳`, `ה׳ צב-אות`, `א-ל`, «Б-г», G-d, L-rd, G-tt (переводы Sefaria
   правит `scripts/fetch-sources.py`); гиматрия — по настоящему написанию.
6. Новые термины — в `src/i18n/glossary.ts`.
   Транслитерация иврита по-русски: ה в начале и в середине слова — **ґ** (ґа-Турим, Авраґам, Йеґуда, Теґилим, Зоґар,
   артикль «ґа-»); ה на конце не пишется (Тора, Шхина, Моше). ח — «х», как и было.
7. Проверка: `npm run check`, сборка, прохождение урока в браузере (ru/en/de, 390/360 px), PDF печати.

## «Читать» — урок без счёта

У каждого урока с гиматриями (все, кроме `kind: 'sicha'`) есть пункт меню «Читать» (`#/<slug>/read`,
`src/components/ReadPage.tsx`): весь урок лентой — условие, карточки слов с готовыми суммами, у каждого шага готовый
ответ с расчётом (из того же `coach`, что проверяет `npm run check`), разгадка, разделы урока, первоисточники,
конспект, «Ґораа ле-поаль» и приглашение сыграть. Ссылки: меню (`lessonGames.ts`), кнопка в шапке урока,
строка под условием нерешённой загадки, значок книги на плитке главной. Новый урок попадает туда автоматически.

## Перевод, режим чтения, «слушать»

- Язык страницы — `<html lang>` (ставит i18n); урок на запасном языке помечает свой блок `lang`.
- Весь иврит (`.he`, `.heb`, `[lang="he"]`) получает `lang="he" translate="no"` — `src/core/langMarkup.ts`
  (на сайте — сам, через MutationObserver; в статических страницах — `markHebrewHtml` в `scripts/prerender.ts`):
  переводчик браузера не трогает слова Торы и Имена, голос читает их как иврит. Новый иврит — просто класс `he`.
- Страницы чтения (`ReadPage`, `CardsReadPage`) — один `<article>` с `h1`, автором (`.author`) и разделами
  `<section>`: так их берут режим чтения браузера (проверено Readability) и «прочитать вслух». Декоративное
  (плитки букв) — `aria-hidden`; не для голоса — класс `no-speak`. `og:title` следует за `document.title` (`pageMeta.ts`).
- Кнопка «🔊 Слушать» (`Listen.tsx`, `src/core/speech.ts`) — голос браузера (Web Speech API, без сети), по абзацам
  с подсветкой, иврит — ивритским голосом, если он есть на устройстве. Статическая `/<slug>/` содержит весь пересказ.
- «🔈 Проверить звук» рядом — говорит одну фразу и сообщает, может ли браузер воспроизвести речь: нет голосов, нет голоса
  для языка, браузер не разрешил, звук занят, звук не начался (громкость/без звука) — `checkSpeech` в `speech.ts`.
  Те же сообщения — если «Слушать» не зазвучало.

## Разрешения браузера — никаких

Сайт не просит у браузера ни микрофон, ни камеру, ни местоположение, ни уведомления, ни распознавание речи:
город для Шабата — по часовому поясу, «Слушать» только говорит (синтез речи разрешения не требует), буфер обмена
и «поделиться» — по нажатию, без запроса. `npm run check` ругается на такие API в `src/`.

## «Знаете ли вы?» — лента загадок

Пункт меню «Знаете ли вы?» (`#/facts`, `src/components/FactsPage.tsx`, данные — `src/core/facts.ts`): все равенства
и буквенные намёки уроков с гиматриями лентой, **без объяснений** — вопрос «А вы знаете, чему равно …?» / «какое слово
спрятано в первых (последних) буквах …?», ответ по нажатию и ссылки **на то место в уроке**: «Где это в уроке:
загадка N» (`#/<slug>/read/N` — чтение, открывается на загадке), «Разгадать самому» (`#/<slug>/r/N` — игра на этой
загадке), «В Memo-игре: пара N» (`#/<slug>/memo/N` — «Изучите пары» на этой паре).
«📤 Поделиться загадкой» — картинка 1080×1350 (`renderFactCard` в `src/core/shareCard.ts`): загадка (вопрос, иврит
с переводом) и под чертой «Ответ» — ответ с переводом; «Почему так — на сайте», подпись niflaot.mychitas.app;
к картинке — текст (загадка, ответ) со ссылкой
`#/facts/<id>` (лента открывается на этой карточке; id постоянный — от слов загадки).
Ответ — **без расчётов**: только число и равные ему слова/выражения, в столбик («האדם ? = 50 = אדמה»); суммы чисел
(«456 + 15») не показываются; равенства одной загадки с тем же числом — одна карточка («פרצוף + גאוה = 471 = זנב + תאוה»).
Собирается само: пары Memo, `equations` загадок (только чистые равенства гиматрий — каждая часть проверяется кодом),
шаги «Собери слово»; повторы убираются. Каждое ивритское слово ленты должно иметь перевод в `glossary` урока
на всех языках, и у каждого факта есть место в уроке (загадка или пара Memo) — это проверяет `npm run check`.

## «Нифлаот Ребе»

В каждой главе — пункт меню и раздел на главной «Нифлаот Ребе» (`#/rebbe/<parsha>`, «Чудеса Торы в учении Ребе»),
**без гиматрий**. Урок раздела — `series: 'rebbe'`, `kind: 'sicha'`; две игры: «Расследование» (`#/<slug>`) и «Карточки»
(`#/<slug>/cards`, стих ↔ одно объяснение Ребе на стих); в меню — сразу под «Нифлаот Ребе»: «<название урока>»
(расследование), «Карточки» и «Прочитать» (`#/<slug>/read`, `CardsReadPage.tsx`) — все пары «стих — объяснение
Ребе» подряд, с переключателем «📖 Прочитать / 🎵 Запомнить в стихах» (`#/<slug>/read/poem`): у каждой пары
`poem` в `cards.items` — 4–6 рифмованных строк на каждом языке (стих, объяснение, вывод — ничего от себя), это проверяет
`npm run check`. Подробно — `docs/LESSON-GUIDE.md`.

## Правило: у урока-комментария — две игры

У урока по комментарию (`kind: 'commentary'`, Бааль ґа-Турим) **два подменю, равноправных и доступных в любой момент**:
«Игра с гиматриями» (`#/<slug>`, загадки) и «Memo-игра» (`#/<slug>/memo`). Обе игры — подпунктами урока в меню
(`lessonGames.ts`) и на карточке урока на главной; переключателя под шапкой урока нет (он дублировал меню);
в итоге гиматрий — приглашение в Memo.
- Языки игры — языки сайта (ru, en, de). Иврит — только слова Торы и цитаты комментария, всегда с переводом.
  Отдельного ивритского интерфейса пока нет.
- Методика Memo: «Изучите пары» → лёгкая игра (6 пар) → полная (12) → «Что мы узнали». На карточках-картинках подписей нет;
  под игрой — список «Что на картинках» (`title` + `caption`: что изображено и что это значит) — он связывает картинку
  со словами Торы. Карточка слов — иврит + перевод. После пары — «Бааль ґа-Турим пишет» (иврит + перевод), «Знаете ли вы?», гиматрия/игра букв с расчётом,
  «Чему это учит?».

## Правило: в Шабат сайт отдыхает

За час до захода солнца в пятницу и до часа после захода в субботу (с запасом в обе стороны) **для города
пользователя** вместо сайта — экран «Шабат шалом» и время, когда сайт откроется (`src/core/shabbat.ts`, `zmanim.ts`,
`places.ts`, `src/components/ShabbatRest.tsx`). **Ґалахических времён и слов на сайте нет** («зажигание свечей»,
«исход Шабата» не показываем — это ответственность общины). Город — по часовому поясу устройства (без запроса
геолокации); пояс не из списка или нет захода солнца — с 14:00 пятницы до 23:00 субботы по часам устройства.
Сайт закрывается и открывается сам (проверка раз в 30 с). Таймер «Осталось играть на этой неделе» на главной считает
до того же момента.
Посмотреть экран в любое время: `?shabbat=preview`.
